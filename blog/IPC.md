# IPC

IPC（Inter-Process Communication，进程间通信）是指操作系统提供的、让多个相互隔离的进程之间传输数据或信号的一组技术与方法

**进程隔离**：每个进程拥有独立的虚拟地址空间，进程间无法之间访问各自内存。（操作系统控制的）

IPC的作用

- **传输数据**:把数据从一个进程安全送到另一个进程（管道、消息队列、共享内存、Socket）。

- **同步控制**:让多个进程协调执行顺序、避免冲突（信号量、信号）。

### 主要 IPC 方式一览

| 方式             | 特点                                                     | 典型场景                                                                                                                     |
| ---------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **管道（Pipe）** | 单向字节流；匿名管道限亲缘进程，命名管道（FIFO）无此限制 | 命令行 `\|`、父子进程简单传输                                                                                                |
| **消息队列**     | 内核维护的结构化消息链表，可按类型异步收发               | 离散消息、异步通信                                                                                                           |
| **共享内存**     | 多进程映射同一块物理内存，**速度最快**；需配合信号量同步 | 大数据量、高频通信（数据库、图形处理）                                                                                       |
| **信号量**       | 计数器，只做同步互斥，不传数据                           | 保护共享资源的访问秩序           |
| **信号**         | 异步通知，信息量极小                                     | 进程控制（kill、中断处理）                                         |
| **套接字**       | 最通用：本机通信用 Unix Domain Socket，跨主机用 TCP/UDP  | 网络通信、本地服务（数据库客户端） |

> 其中 Socket 和 Streams 还支持**不同主机**间的进程通信**
